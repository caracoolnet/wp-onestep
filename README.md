# Caracool OneStep

Plugin WordPress de Caracool: desactiva comentarios en todo el sitio y activa un modo de mantenimiento con pagina personalizable, en un unico plugin ligero sin dependencias externas.

## Instalacion

Descarga el .zip de la ultima release y subelo desde WordPress -> Plugins -> Anadir nueva -> Subir plugin.

## Uso

Desde wp-admin -> Caracool OneStep se activan dos interruptores independientes: desactivar comentarios en todo el sitio (incluyendo REST y XML-RPC), y modo mantenimiento (por defecto solo el administrador logueado ve la web real).
